# STYLE LAB 👕
### Explorando estilos, cores e combinações de roupas

## Sobre o projeto

O **STYLE LAB** é um site desenvolvido com o objetivo de explorar o universo da moda, ajudando os usuários a conhecer diferentes estilos de vestimenta, entender combinações de cores e experimentar possibilidades de looks.

A proposta é oferecer uma experiência visual, intuitiva e interativa, permitindo que o usuário explore referências de moda, descubra diferentes estilos e monte combinações de roupas de acordo com suas preferências.

O projeto foi desenvolvido como parte da disciplina de **Desenvolvimento de Interfaces**, utilizando tecnologias fundamentais do desenvolvimento web.

---

## Objetivos

- Apresentar diferentes estilos de moda e suas características.
- Explorar combinações de cores aplicadas ao vestuário.
- Permitir que o usuário experimente combinações de peças.
- Criar uma interface visual agradável e intuitiva.
- Aplicar conceitos de UI, UX, acessibilidade e design responsivo.
- Proporcionar uma experiência de navegação simples e interativa.

---

## Funcionalidades

### Página inicial
Apresenta a identidade do STYLE LAB, introduz a proposta do site e permite que o usuário navegue pelas principais áreas através de seções de destaque, carrosséis e links de navegação.

### Explorar estilos
Apresenta diferentes estilos de vestimenta através de cards, imagens e descrições, permitindo que o usuário conheça suas características e referências visuais.

### Guia de cores
Apresenta paletas de cores e suas combinações, auxiliando o usuário a compreender como diferentes tonalidades podem ser utilizadas na composição de looks.

### Montar Look
Área interativa onde o usuário pode explorar peças de roupas e montar combinações, visualizando as peças selecionadas e acompanhando a composição do look.

### Modo claro e escuro
O site possui um sistema de alternância entre tema claro e escuro, proporcionando maior conforto visual e permitindo que o usuário escolha sua preferência de visualização.

## Design e identidade visual

A identidade visual do STYLE LAB foi desenvolvida buscando transmitir modernidade, criatividade, personalidade e elegância.

A interface utiliza uma combinação de tons neutros, terrosos e elementos contrastantes, criando uma estética relacionada ao universo da moda e facilitando a organização visual dos conteúdos.

A escolha das cores foi pensada para criar uma experiência visual equilibrada, utilizando tonalidades que transmitem conforto, sofisticação e criatividade.

O projeto também conta com um modo escuro, adaptando os elementos da interface para uma visualização mais confortável em ambientes com pouca iluminação.

---

## UI e UX

Durante o desenvolvimento, foram aplicados conceitos de **UI (User Interface)** e **UX (User Experience)**.

### UI — Interface do usuário
A interface foi construída buscando manter consistência visual entre as páginas, utilizando padrões de organização, tipografia, espaçamento, cards, botões e elementos de navegação.

### UX — Experiência do usuário
A experiência foi pensada para facilitar a navegação e tornar a exploração do conteúdo mais intuitiva, reduzindo dificuldades de interação e permitindo que o usuário encontre as funcionalidades de forma simples.

Entre os aspectos considerados:

- Organização clara das informações.
- Navegação intuitiva.
- Consistência entre as páginas.
- Feedback visual em elementos interativos.
- Facilidade de utilização.
- Adaptação para diferentes tamanhos de tela.

---

## Acessibilidade e responsividade

O STYLE LAB busca aplicar princípios de acessibilidade e responsividade, visando tornar a interface mais confortável e utilizável por diferentes usuários e dispositivos.

Foram considerados aspectos como:

- Contraste entre textos e fundos.
- Legibilidade dos conteúdos.
- Organização hierárquica dos elementos.
- Identificação clara de botões e links.
- Adaptação dos layouts para diferentes resoluções.
- Alternância entre modo claro e escuro.

Esses aspectos contribuem para uma experiência de navegação mais acessível e consistente.

## Como executar o projeto

O STYLE LAB é um projeto web front-end.

### 1. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acessar a pasta do projeto

```bash
cd STYLE-LAB
```

### 3. Abrir o site

Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto em um servidor local e facilitar a visualização das alterações durante o desenvolvimento.

## Processo de desenvolvimento

O desenvolvimento do STYLE LAB foi realizado em etapas:

1. Definição da proposta e identidade do site.
2. Planejamento das páginas e funcionalidades.
3. Construção da estrutura HTML.
4. Desenvolvimento da identidade visual utilizando CSS.
5. Implementação das funcionalidades com JavaScript.
6. Criação de elementos interativos, como carrosséis e montagem de looks.
7. Implementação do modo claro e escuro.
8. Ajustes de responsividade e visualização em diferentes dispositivos.
9. Testes de navegação e correção de erros.
10. Revisão e refinamento da interface.
